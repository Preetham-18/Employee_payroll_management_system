# Employee Payroll Management System

A Command Line Interface (CLI) based Employee Payroll Management System developed using Python. This project demonstrates the fundamentals of Python programming, including Object-Oriented Programming (OOP), functions, loops, conditional statements, and data structures.

## Features

* Add Employee
* View All Employees
* Search Employee by Employee ID
* Update Employee Details
* Delete Employee
* Calculate Salary (Bonus, Tax & Net Salary)
* Find Highest Paid Employee
* View Department-wise Employees

## Technologies Used

* Python 3
* Command Line Interface (CLI)

## Python Concepts Covered


3. Run the program:

